# HPM 知识库插件

[English](README.md) | [简体中文](README.zh-CN.md)

`hpm-knowledgebase` 帮助你查找和阅读 HPMicro 技术资料，包括芯片手册、SDK 代码、开发板文档和知识库文章。

## 可以查询什么

- 芯片数据手册、用户手册、寄存器说明及勘误。
- SDK 驱动、API 用法及示例代码。
- 开发板原理图、接口、启动配置及用户指南。
- 知识库文章、常见问题、故障排查及使用经验。

可查询资料和 SDK 版本以服务当前收录内容为准。提问时提供芯片或开发板型号、SDK 版本，可以得到更准确的结果。

## 开始使用

1. 按照[安装说明](../../README.zh-CN.md#安装插件)安装并启用 `hpm-knowledgebase`。
2. 根据客户端提示完成登录。
3. 直接描述问题，并要求提供相关资料出处。

插件连接 `https://kb.hpmicro.com/llm/mcp`，需要能够访问该服务，不需要在本地安装 SDK 或构建工具。

## 示例提示词

```text
使用 HPM 知识库插件，查找适用于我的芯片和 SDK 版本的 UART 示例。
使用 HPM 知识库插件，解释这个寄存器字段，并给出对应的手册章节。
使用 HPM 知识库插件，查询这块开发板的启动配置和接口连接。
使用 HPM 知识库插件，查找这个错误的相关文章，并总结解决方法。
使用 HPM 知识库插件，确认这个 API 的用法，并提供资料出处。
```

直接说明任务即可，不需要指定具体工具名称。

## 常见问题

- 无法连接：检查网络连接，以及插件是否已启用。
- 提示登录：根据客户端提示重新登录。
- 没有找到相关资料：补充芯片/开发板型号、SDK 版本、完整错误信息，或缩小问题范围。

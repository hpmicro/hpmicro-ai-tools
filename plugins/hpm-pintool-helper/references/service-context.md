# 远程 MCP 会话与目标选择

使用本插件 `.mcp.json` 中 `hpm-pintool-helper` 提供的工具。客户端可能给工具名加命名空间，以实际公布的名称和输入 schema 为准。工具不可用时说明需要启用插件或完成连接；不把本地 SDK CLI 当作这些远程查询/生成工具的替代实现。

服务需要远程 HTTP MCP/OAuth，逐次验证 bearer token，scope 为 `hpm-tools:mcp`， audience 为 `hpm-tools-mcp`。授权失效时通过客户端刷新；失败再重新登录。不要把 token 写进工程或插件文件。权限被拒绝时报告当前目标和原因，保留用户选择。

目标使用用户工程中的 SDK/SoC/封装；缺少必要信息时先从工程查找，再询问缺失项。尚未查询该 SDK 的可访问目标时，调用 `get_soc_package_list({ sdkName })`，验证目标及所需封装确实存在。返回列表受账号基础公共范围和激活权益过滤。切换 SDK/SoC/封装后，重新查询受影响的元数据。

`NA` 是预览数据集，不等同于最新正式 SDK。pinmux/clock 生成能力由服务按 SoC 分别启用；可查询不代表可生成。生成被拒绝时报告该限制，不擅自改用其他 SDK/SoC。

工具返回 MCP 文本：对象通常是序列化 JSON，代码可能直接是文本。先检查 `isError`，再解析内容；错误文本不能保存成成功产物。元数据和代码生成结果不表示真实板卡状态，也不证明编译或硬件测试通过。按用户范围返回结果或保存文件，报告实际执行的验证；烧录、构建及硬件调试另按用户请求执行。
